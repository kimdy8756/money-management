# 💰 나만의 용돈 관리

수입과 지출을 기록하고 현재 잔액을 확인할 수 있는 간단한 웹 프로그램입니다.

## 주요 기능

- 수입 및 지출 내역 등록
- 총수입, 총지출, 현재 잔액 자동 계산
- 거래 내역 조회
- 거래 내역 개별 삭제 및 전체 삭제
- 브라우저의 `localStorage`를 이용한 자동 저장
- PC와 스마트폰 화면에 맞춰지는 반응형 디자인

## 사용 방법

1. 거래 종류에서 수입 또는 지출을 선택합니다.
2. 금액과 거래 내용을 입력합니다.
3. `내역 등록하기` 버튼을 누릅니다.
4. 상단에서 총수입, 총지출, 현재 잔액을 확인합니다.
5. 필요하면 거래 내역의 `삭제` 또는 `전체 삭제`를 사용합니다.

## 실행 방법

`index.html` 파일을 웹브라우저에서 열면 실행할 수 있습니다.

## GitHub Pages 배포 방법

1. GitHub에서 `money-management`라는 이름으로 새 Public 저장소를 만듭니다.
2. 이 저장소에 `index.html`과 `README.md`를 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 Source를 **Deploy from a branch**로 선택합니다.
5. Branch는 **main**, 폴더는 **/(root)**를 선택하고 **Save**를 누릅니다.
6. 배포가 완료되면 `https://깃허브아이디.github.io/money-management/` 주소로 접속합니다.

## 참고

거래 내역은 입력한 브라우저의 로컬 저장 공간에 저장됩니다. 따라서 다른 기기나 다른 브라우저와 거래 내역이 자동으로 동기화되지는 않습니다.
